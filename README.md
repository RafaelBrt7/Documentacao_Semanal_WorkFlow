# Documentação-Semanal-WorkFlow
### Resumo da Semana 
**Aula 1:** Não houve aula prática, porem consegui ter uma boa base sobre todos os fundamentos passados, eles são: JS(Javascript), CSS(Cascading Sheets Style) e HTML(Hyper Text Language). O HTML é como uma estrutura funcional do corpo ex: O esqueleto. Ele Serve como um sistema por trás de todo o corpo o humano, dando suporte a movimentos, e a sustentação do corpo, como uma estrutura de um site, Se você remover a estrutura HTML, o navegador receberá apenas texto cru, Tecnicamente "A falta do HTML" é como se retirar-se a espinha dorsal do corpo, perderia toda estrutura, Já o CSS retirar-lo, Não influenciará o código, porém ele perderá toda a parte estetica e estilizada, deixando a imagem do site bem básica ou sem detalhes, Javascript é um linguagem de programação que dá dinâmicas para uma estrutura de um código, permitindo animações, validação de dados e funcionalidades complexas no navegador.

**Aula 2:** Houve uma prática, onde criamos uma estrutura em HTML, Para fazermos uma análise da idade do usuário atribuído, Criando assim um leitor que realizará uma diferença entre sua idade de nascimento ao ano atual, Ex: Nascimento "2007", Ano atual "2026", O Programa realiza uma diferença entre os valores, Achando a idade do indivíduo que é 19 anos.

**Aula 3:** Não tivemos prática, mas com base a aula teorica, Aprendi sobre os comandos Linux/Unix, aprendi a diferença entre shell(Interface de texto) e GUI (interface gráfica). cd (entrar/pastas), usados para criar e oranizar o arquivo

**Aula 4:** Aprofundi na linguagem Javascript, Apredi sobre a armazenamento de diferente tips de dados,A prática se resumiu a criar um código que calcule uma soma de 3 números e dividir-los por 3, achamos uma média do resultado, para criar, usaremos: Int (Para números interios) e double/float (para decimais), let, const e var.
